## Condició d'activació (§9.1)

Aquesta part **s'activa només** quan la Fase 10 està completada i el sistema ha operat
**60 dies consecutius** d'operativa estable amb **≥1 venda setmanal** (§1.9).

**Estat: NO ACTIVAT.** La condició no es compleix.

## Pressupost (§9.1.A, OP-004 TANCAT)

| Partida | Pressupost mensual |
|---|---|
| Publicitat de pagament (Instagram/Meta Ads) | 0–50 € (opcional) |
| Fanzine | Cost variable per edició |
| Newsletter i automatització | 0 € |
| Contingut (fotografia, disseny) | 0 € |

El pressupost mensual d'activació **no supera els 50 €** mentre la governança no decideixi
explícitament ampliar-lo.

## Canals (§9.2.1)

Fase 11; qualsevol ampliació segueix el calendari de §9.1.A.
