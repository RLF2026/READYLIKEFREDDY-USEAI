Vector:
No traced-path vector is included. Forced auto-tracing would modify/destroy the source's distressed micro-texture, so it would not be AAA-faithful. The SVG is explicitly named RASTER_PRESERVADA and is not presented as native path vector.

4096 px master; 2048 px web. Source image was 1280 px wide, so the 4096 px masters are high-quality upscales, not invented extra detail.
